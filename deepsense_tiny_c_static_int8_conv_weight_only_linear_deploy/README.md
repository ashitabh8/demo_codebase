# ACIDS DeepSense C Inference Package

This directory is a self-contained C inference package for the quantized DeepSense audio model.

## Build And Run

```bash
cd /home/misra8/demo_codebase/src2/experiments/deepsense_tiny_c_static_int8_conv_weight_only_linear_deploy
make
./acids_infer
```

Running `./acids_infer` with no arguments runs all packaged samples in `samples/`.

To run one explicit sample:

```bash
./acids_infer samples/Gv3c1090_96.bin
```

## Input Format

Each sample is raw float32 binary with this flattened shape:

```text
[C=3][segments=7][T=256]
```

This matches the Python ACIDS dataset tensor before preprocessing:

```text
audio: (3, 7, 256)
```

The C runner uses only audio channel 0, matching the Python experiment setting.

## Data Flow

```text
sample .bin
  -> main.c
  -> acids_audio_preprocess_ch0_segments_chw()
  -> acids_decimate_segment_256()
  -> acids_segment_mel_len()
  -> model_forward()
  -> argmax logits
```

## Main Files

`main.c`

- Opens one or more raw sample binaries.
- If no input path is provided, loops through packaged samples from `acids_samples.h`.
- Calls `acids_audio_preprocess_ch0_segments_chw()`.
- Calls `model_forward()`.
- Prints expected class, predicted class, logits, and match status.

`acids_samples.h`

- Lists packaged sample names, paths, expected label ids, and expected label names.
- Generated from the Python reference manifest.

`acids_class_names.h`

- Maps model output indices to class names:

```text
0 -> background
1 -> 3
2 -> 6
3 -> 8
4 -> 9
```

`acids_mel_preprocess.c/.h`

- Implements C preprocessing before model inference.

`model.c/.h`, `weights.h`

- Generated by Tiny-NN-in-C.
- `model_forward(const float *input, float *output)` expects post-mel model input.

## Preprocessing Details

Entry point:

```c
int acids_audio_preprocess_ch0_segments_chw(const float *input_chw, float *out_chw);
```

Input:

```text
input_chw: [3][7][256] float32, flattened CHW
```

Output:

```text
out_chw: [1][7][80] float32, flattened CHW
```

### Channel Selection

The function selects channel 0:

```text
input channel 0 -> [7][256]
```

Channels 1 and 2 are ignored.

### Downsampling

Each of the 7 segments is downsampled independently.

Python reference:

```python
AudioDownsampler(input_sr=16000, target_sr=1600)
```

C equivalent:

```c
acids_decimate_segment_256()
```

Settings:

```text
input sample rate: 16000 Hz
target sample rate: 1600 Hz
decimation factor: 10
FIR taps: 101
FIR padding: 50
cutoff: 0.45 * 1600 = 720 Hz
```

The segment length is 256 samples. Python trims the last 6 samples because 256 is not divisible by 10:

```text
256 -> trim to 250 -> decimate by 10 -> 25 samples
```

The C code mirrors that behavior.

### Mel Preprocessing

After downsampling, each segment has 25 samples. The mel step uses `n_fft=160`, so the 25-sample segment is zero-padded to 160 samples before the RFFT.

Mel parameters:

```text
n_fft: 160
mel_bins: 80
fmin: 20.0 Hz
fmax: 800.0 Hz
sample_rate: 1600 Hz
log epsilon: 1e-6
```

Pipeline per segment:

```text
25-sample downsampled segment
  -> zero-pad to 160
  -> RFFT, 81 bins
  -> power spectrum
  -> mel filterbank [80][81]
  -> log(mel + 1e-6)
```

Tables:

- `acids_fir_taps.h`: FIR low-pass taps.
- `acids_rfft_tables.h`: RFFT basis matching `torch.fft.rfft`.
- `acids_mel_tables.h`: mel filterbank matching Python `MelPreprocessor`.

## Model Input And Output

Model input after preprocessing:

```text
[1][7][80] float32
```

The generated model uses Tiny-NN-in-C layout internally. The public generated model header says the C boundary expects NHWC for direct model calls. In this package, `main.c` does not call the model directly on user data; it first calls the preprocessing function, then passes the produced buffer to `model_forward()`.

Model output:

```text
logits[5]
```

The runner uses argmax over these 5 logits.

## Quantization

This package uses:

```text
Convolution layers: static int8
Linear/projection layers: weight-only int8 per-channel
Activations around Linear layers: float32
```

This compresses the large projection layer while avoiding the accuracy drop seen with fully static int8 Linear activation quantization.

# Arduino Demo Firmware

This sketch runs model inference on flashed demo samples and streams predictions to the PC over Serial.

## Serial Protocol
- Ready line:
  - `ready src=arduino commands=START,STOP,RESET,STATUS`
- Prediction line:
  - `sample_<id> src=arduino pred=<int> target=<int> inf_ms=<float> logits=<v0,v1,...>`
- Ack line:
  - `ack src=arduino cmd=<START|STOP|RESET>`
- Status line:
  - `status src=arduino running=<0|1> cursor=<idx> total=<N>`
- End line:
  - `done src=arduino`

## Commands
- `START` begin streaming inferences.
- `STOP` pause streaming.
- `RESET` reset cursor to sample 0 and pause.
- `STATUS` print current runtime status.

## Required Files in Sketch Folder
Copy these into the same Arduino sketch folder as `arduino_demo.ino`:
- `model.h`
- `model.c`
- `weights.h`
- `nn_ops_float.h` (and int8/int16 ops headers if used by generated model)
- `demo_samples.h` (generated by `export_demo_samples.py --export_header`)

## Build Notes
- Default serial baud is `115200`.
- If your generated model output dimension differs, set `MODEL_OUTPUT_SIZE` before compile.
- `demo_samples.h` must provide:
  - `DEMO_NUM_SAMPLES`
  - `DEMO_FEATURE_SIZE`
  - `DEMO_SAMPLES`
  - `DEMO_TARGETS`
